# Delivery Tracker

The final mile — tracks whether epics and tasks have actually shipped to their intended destination.

## Responsibility

- Validate that completed epics and tasks have been delivered end-to-end, not just marked done internally.
- This is the last checkpoint: did it ship to the last mile of the delivery?
- Provide a release-level view of what has been delivered vs. what is still in flight.

## Scope

- Purview is all epics under the current release for the team.
- Works in conjunction with Epic Status and Task Status to give a complete picture of delivery health.
