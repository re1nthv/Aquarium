# Coding Tasks

Handles execution of tasks that are coding in nature.

## Responsibility

- Receive coding tasks from the Executor.
- Identify the appropriate repository where the task needs to be developed.
- Carry out the implementation within that repo — scoped to the right codebase and branch.

## Behaviour

- Before executing, confirm the correct repo is identified to avoid cross-repo contamination.
- Execution follows the dependency order established by the Story Shuffler.
